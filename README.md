# carrito-uy-app

## Scrape

# Modo interactivo

npx cypress open

# Modo headless (automatizado)

npx cypress run --spec "cypress/e2e/scrape.cy.js"

# Con más detalle en consola

npx cypress run --spec "cypress/e2e/scrape.cy.js" --browser chrome

# Run app

npx expo start

## run app sin cache

npx expo start -c
